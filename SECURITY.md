# Security

## Reporting a vulnerability

Please report security problems **privately**, not in a public issue.

1. Open the **Security** tab of this repository.
2. Choose **Report a vulnerability** and describe what you found.

If you do not see that button, open a normal issue that says only "I would like to report a security problem" with no details, and a maintainer will arrange a private way to talk.

## What is in scope

- The website and its code in this repository
- The Firestore security rules in `firestore.rules`

## Good to know

- The Firebase web settings in the deployed site are public by design. They identify the project and are not secrets. Access to data is controlled by the security rules.
- Players should use nicknames, not real names.
